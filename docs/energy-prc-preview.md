# PR C 第二版：整合画面与能耗档位

根据 iPad 第九代用户实测与确认，本版替换第一版实验面板，将方案整合进原设置 → 数据中的“画面效果与能耗设置”。不涉及 3D 展厅，不自动合并正式站。分支预览直接打开首页即可，不需要 URL 参数；旧 `energyPreview` 参数不再启用额外行为。

## 三档与兼容模式

| 档位 | 行为 |
| --- | --- |
| 舒适省电 | 使用均衡基础配置，选中的动态背景替换为相应配色的静态渐变底图；不挂载 Canvas、WebGL 或背景动画。天气及选定悬浮装饰保持静态；毛玻璃、文字与短时业务反馈保留。 |
| 推荐均衡（默认） | 保留 PR B 均衡背景密度及 WebGL 分辨率/帧率，仅为万象字阵启用停留停绘、有界字形缓存和按时间推进。其他背景、天气保持 PR B 实现。 |
| 完整视觉 | 沿用原画质背景实现；不启用 C 的绘制或天气改动。持续动态运行仍可能增加发热和耗电。 |
| 高级选项：旧设备兼容 | 沿用旧轻量实现，替代三档之一，不与它们叠加。不宣称最省电。 |

静态底图保留背景的整体配色与氛围，不承诺逐像素复刻动态画面。装备数据不改变，切回动态档后恢复原装备背景。所有档位保留毛玻璃，不启用首版关闭毛玻璃或天气参数缓存实验。

## 独立空闲节能

- 默认开启；20 秒无操作后暂停指定背景、天气、NPC 浮动及部分宠物装饰动画。
- 点击、触摸、滚动、按键恢复，不阻止默认事件或吞掉第一次点击。持续按住/拖动时不判为空闲，结束后重新计时。
- 切换背景或档位恢复装饰，避免新画布挂载在暂停状态出现空白。
- 页面隐藏或 pagehide 停止装饰，恢复时不补跑隐藏时段。旋转尺寸由背景原 resize 逻辑处理。
- 舒适省电的装饰始终静态，因此空闲开关置灰，但保留其偏好；切回动态档后继续使用。
- 不改业务时间：任务倒计时、同步、扣款和领奖逻辑保持原行为。CSS 暂停仅针对指定装饰，不统一暂停所有动画或定时器。

## 迁移和设备策略

| 原设置 | 新设置 |
| --- | --- |
| auto / 自动 | 推荐均衡 |
| balanced / 均衡 | 推荐均衡 |
| disabled / 原画质 | 完整视觉 |
| enabled / 轻量 | 旧设备兼容 |
| 仅有 low_perf_manual=true / false | 旧设备兼容 / 完整视觉 |
| 无设置或存储不可读 | 推荐均衡，空闲节能开启 |

手机、平板和桌面的首次默认均为推荐均衡。启动时只读取保存档位，不再创建探测用 WebGL 上下文或运行两秒 FPS 基准。硬件检测事件不覆盖手动档位，不根据屏幕宽度、旋转或一次慢帧调档，也不猜测具体 iPad 代数。

继续使用设备本地键 `device_graphics_quality_v1`，新增 `device_idle_energy_v1`；均不使用参与家庭同步的 `app_` 前缀。旧 low_perf_manual 同步写入兼容值，避免启动脚本错误使用旧档位。开启/关闭空闲节能不修改画质或装备。

## 取舍依据与限制

用户实测均衡＋万象字阵在绘制优化后改善，因此保留这项优化。轻量＋无背景在首版绘制/合成方案下反而发热，根因未确证，故撤下其他 C 绘制、天气和合成改动，恢复 PR B 基线。定格明显改善，故保留独立空闲节能以及静态档。

不宣称三个档位均经过真机功率测量，也不承诺动态档完全不发热。测试结果由开发方负责验证，用户不再承担组合试验。

## 自动回归范围

新档位测试替换已撤下的实验面板测试，保留会计、同步、PR A 和安全区回归。重点覆盖：

- 旧设置迁移、默认值、持久化、设备检测不覆盖设置、家庭同步隔离。
- 所有 12 种背景在静态档均不创建画布/动画循环，切回动态档正常恢复。
- 字阵静止零绘制/回调、移动时缓存复用；完整视觉/兼容模式仍使用基线。
- 空闲暂停 CSS 伪元素与 Canvas、首次点击、持续触摸、滚动、页面隐藏/恢复、旋转和背景切换。
- 业务倒计时继续、反馈动画未冻结、毛玻璃保留。
- 四种 WebGL 维持 PR B 像素尺寸和绘制频率，空闲/切换释放调度。
- 真实 App 设置可用、装备不变、刷新保留、旧预览参数不启用面板。

WebKit 软件运行环境不提供 WebGL，相关项目明确跳过并由 Chromium 软件渲染覆盖；自动回归不是 iPad 真机功率测量。
