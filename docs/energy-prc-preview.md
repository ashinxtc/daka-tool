# PR C：减少持续绘制，并隔离合成与空闲开销

本次针对 iPad **第九代**的实际反馈。代码基于已合并的 PR B；PR C 先发布分支预览，不自动合并正式站，不涉及 3D 展厅。

## 已知与未知

用户实测：均衡＋无背景明显好于动态背景；轻量＋无背景从冷机开始仍更热。这个结果不能用上一轮余热解释，也不能据此认定某个 CSS 属性或设备硬件就是根因。

新增真实 App 的自动审计在无特效背景、固定样例数据、无家庭同步绑定的条件下，交替采样均衡/轻量各两次（每次 10 秒）：两个浏览器均未发现残留背景 Canvas/rAF、整棵 App 的周期重绘或采样期间新增 fetch。轻量的持续 CSS 动画和模糊元素数量反而较少。Chromium 仍有局部时钟组件提交；不等同于整个页面重绘。这些计数**不能测量 GPU 合成、整机功率或温度**，也不覆盖用户的全部数据和在线同步负荷。轻量更热的原因仍未被复现。

代码可确认的改进点：字阵静止阶段仍连续绘制；甲骨流沙默认中心指针持续注入能量；已有 WebGL 限帧仍在每个屏幕帧回调；动态阴影和动态背景后方的毛玻璃可能增加绘制/合成成本。最后一项需要对照验证，不能只凭代码断言是 iPad 发热根因。

## 预览方式

在 PR 的 Vercel Preview 地址后添加 `?energyPreview=c`。若 Vercel 要求登录，使用项目有权限的账号。预览域名拥有独立存储；不需要为了特效测试绑定家庭同步。面板只隔离画质和背景选择，业务操作仍是真实应用行为。

固定“均衡 B”和同一背景，依次选择：

| 方案 | 改动 | 视觉/交互影响 |
| --- | --- | --- |
| 当前版本 | PR B 基线 | 保持现有效果 |
| 绘制优化 | 缓存字形、静止停绘、Canvas 时间推进及约 30fps 绘制、减少 WebGL 调度、稳定天气粒子、部分光晕改为固定形状＋透明度变化 | 保留背景种类、粒子数量、文字分辨率和点击交互；高速背景可能不如 60fps 平滑，光晕呼吸略有差异 |
| 绘制＋合成优化 | 上一项＋移除首页 header/main 中毛玻璃元素的 backdrop-filter | 保留卡片底色、边框和背景；背景透过卡片的模糊感减弱，需检查文字可读性 |
| 空闲节能 | 上一项＋20 秒无操作后暂停背景、天气和选定悬浮装饰 | 静置时变成静态画面；点击、滚动、指针移动或按键恢复，不改变业务时间 |

另有“定格背景与天气（业务计时继续）”开关，可在基线上单独比较持续运动负担。切换画质/背景/方案会取消定格，避免新背景挂载在暂停时出现空白。选项仅本次页面有效，刷新回到保存的画质、当前装备、基线方案；不写入云端同步。普通网址以及 PR B 的 `?energyPreview=1` 不启用 C 方案。

建议先测两个最有区分度的组合：

1. **均衡＋无背景**：基线 → 定格 → 合成优化，区分背景之外的天气、装饰及毛玻璃影响。
2. **均衡＋万象字阵**：基线 → 绘制优化 → 合成优化 → 空闲节能，观察停绘和合成各自的贡献。
3. 再用同样组合比较轻量，以检查“轻量更热”是否持续出现；不要同时更换多个条件。

每组保持亮度、网络、音量、操作方式、时长一致；打开后等资源加载稳定、收起面板再比较。每组约 15–20 分钟，之间冷却；交叉测试顺序。记录模式、背景、操作/静置、起止电量、发热和视觉感受。电量百分比粒度粗，不将短时间 1%–2% 波动换算成精确省电比例。

## 实现边界

- 装饰时钟支持可取消的延迟唤醒和手动暂停；页面隐藏、pagehide 与手动暂停共同决定是否运行，恢复时不补跑隐藏时间。只供背景特效使用，业务截止时间仍使用真实时间。
- 字阵使用 1 秒停留＋1.5 秒移动的时间轴；静止阶段一次绘制后定时唤醒。字形缓存上限 512 个 72×72 像素画布（原始像素约 10 MiB，另有对象开销），超限直接绘字避免反复分配；字体加载后清缓存，卸载释放引用。
- 甲骨流沙没有交互时不保留虚拟中心指针；300ms 无新指针输入后能量衰减，位置和能量稳定后停绘。触摸/点击/移动及窗口尺寸变化唤醒。
- 银河、烟花以 60Hz 固定步长模拟、约 30fps 绘制，避免直接跳帧造成整体慢动作；长阻塞最多补 100ms 的装饰模拟。烟花发射和触摸交互保留。
- 四种 WebGL 保留原 B 分辨率规则与时间推进，延迟唤醒减少原生 rAF 回调。CSS 背景不宣称统一限为 30fps。
- 流星星光、萤火虫光点、孔明灯光晕减少动画中阴影半径/滤镜变化；银杏保持 B 绘制方式，受定格/空闲控制。天气随机位置在优化模式中保持稳定。
- 不改扣款、余额、奖励、同步协议、同步频率、任务计时。暂停 CSS 仅作用于指定装饰，保留业务加载及交互反馈动画。
- “轻量”说明改为老旧设备兼容档，不再标注未经实机验证的“省电首选”。

## 验证与限制

自动回归包含原扣款/重复同步/重连/刷新、PR A、PR B、安全区，以及新增停绘/缓存、时间步长、触摸恢复、尺寸变化、延迟任务清理、伪元素暂停、业务倒计时继续、方案切换、真实 App 会话隔离。

浏览器环境为 Chromium 和 WebKit iPad 模拟。WebKit 软件环境不支持 WebGL，相关测试明确跳过，由 Chromium 软件 WebGL 覆盖。自动测试只能证明减少绘制/回调和保持所测业务行为，不能证明 iPad 真机降温或具体省电比例；iOS 主屏幕模式、字形呈现、光晕效果和滚动手感仍需真机对照。

本轮调试修复了 CSS 编译器对 backdrop-filter 声明顺序的兼容差异，以及 :is() 中伪元素选择器被丢弃导致萤火虫未暂停的问题。旋转测试等待真实 resize 事件后验证重新绘制；长时间动画测试缩小软件渲染视口，避免把测试机绘制吞吐限制误判为功能失败。
