# 设备配对与客户端接入（迁移预览）

本批承接服务端授权基础，默认 `AUTH_MODE=legacy` 不变，不自动激活家庭，也不部署生产服务。兑换、推送尚未接入，不能据此开启生产鉴权。

## 已接入的闭环

- `/security.html?code=家庭同步码` 提供管理员激活/恢复、邀请、设备列表、撤销和设备配对。设置页及家长登录页提供入口。
- 管理密钥只留在页面内存；激活前先生成并确认另行保存。刷新、锁定、离开页面或从页面缓存返回会清除管理状态。丢失激活响应后，可用已保存密钥解锁管理，不能自动生成新密钥覆盖。
- 邀请只放 URL fragment，加载立即清除，不进入请求 URL。二维码与链接十分钟内有效；不要公开转发。不同浏览器、Safari 与桌面独立 App 可能不共享存储，须在最终使用环境配对。
- 主程序和家长端凭据分别按家庭/角色存于 `daka_device_access_v1:*`；配对意图在请求前保存于 `daka_pair_pending_v1:*`。响应丢失、刷新及重试复用同一随机 token。存储失败时不发送新的兑换请求。
- 凭据不进入 `app_*` 数据、云端快照或业务备份。管理员密钥不会持久化到浏览器。Bearer 只发送到固定同步服务，拒绝重定向和跨源传递。
- 主程序欢迎同步、手动/自动读写、时间戳查询，以及家长端读写/重试接入各自角色。受保护家庭一旦被识别，持久化标记，不因服务器回退而匿名读取；401 保留本机数据和未确认操作，要求重新授权。
- 受保护快照不采集、合并密码/API key/推送私密配置。本机既有私密设置保留；新设备需独立配置。服务端授权名单始终优先，不能被本机旧名单恢复。空的安全名单拒绝家长指令，旧家庭保留原兼容规则。
- 家长指令/留言使用服务端设备 ID；历史清理保留其他设备记录。撤销自己必须收到服务端确认才删除凭据；本机“已绑定”标记不再触发受保护家庭的自注册。
- 配对页进入主程序前检查已有家庭，发现不同家庭时要求先备份并手动确认切换，不覆盖既有数据。

## 隔离环境的运营步骤

仅在独立测试 Worker/KV/DO 上设置 `SYNC_MODE=active`、`AUTH_MODE=enforced` 和受控 `AUTH_BOOTSTRAP_SECRET`。该开关影响整个服务，不能直接用于渐进开启生产家庭。

在已安全注入环境变量的管理环境运行：

```sh
node scripts/mint-family-activation.mjs TEST_FAMILY activate
node scripts/mint-family-activation.mjs TEST_FAMILY recover
```

脚本只输出一小时签名凭证。不要将引导密钥放入命令参数、版本库、网页或邀请链接。恢复会撤销全部旧设备及邀请，但保留业务数据；随后重新邀请设备。

丢失配对响应时直接重试。放弃待确认配对仅清除本机意图，不撤销服务端可能已经签发的设备，管理员应核查列表并撤销。设备被撤销/到期后，重新取得邀请；此前未确认业务操作保留，不能擅自替换其操作者身份。

## 验证及发布门槛

`tests/deviceAccess.test.js` 覆盖意图恢复、存储失败、角色/家庭隔离、降级保护、撤销确认、私密数据合并及空名单。`tests/e2e/security.spec.js` 使用真实 Chromium/WebKit 页面与隔离 Miniflare 服务验证激活/邀请、配对响应丢失、撤销后禁止自注册、逐笔扣款及刷新不重复执行。

本批没有新增后台轮询、持续动画或能耗档次。沿用现有设备与安全区域回归；浏览器测试不代表真实 iPad 发热测量。

上线前仍须完成 `service-authorization.md` 中兑换事务、扫码核销、推送服务身份和私密配置迁移、新旧客户端混用及生产迁移演练。尤其不能开启鉴权后仍允许兑换依靠本地密码或网络失败离线扣款。当前批次保持独立草稿评审，不合并部署。
