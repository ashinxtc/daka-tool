# PR B：移动端均衡画质预览

本 PR 不自动发布正式站；先使用 Vercel 分支预览，并在网址后加 `?energyPreview=1`。保留 PR A 与 iPhone 安全区修复，不涉及 3D 展厅。

## 使用方式

1. 打开带参数的预览网址，右下角出现“PR B · 同设备画质对比”。
2. 选择同一背景，对比“原画质 A”和“均衡 B”；观察时收起面板，避免面板遮住内容。
3. 可切到“无特效背景”，帮助判断装饰背景在发热中的贡献。这个选项不是新的正式画质档。
4. 面板中的档位、背景仅在本次页面会话有效，不改动装备、库存或已保存的画质选择。刷新后恢复原设置。普通应用的设置页选择则会保存在当前设备。
5. 预览域名拥有独立的网站存储，不会自动带入正式域名的本地数据。可用空白任务页预览背景；无需为画质对比重新绑定同步。正常业务操作仍按应用原逻辑运行，预览面板不是业务沙箱。

## 档位和兼容

| 档位 | 行为 |
| --- | --- |
| 自动 | 老旧硬件沿用轻量档；其他手机、平板优先均衡；桌面沿用原画质 |
| 原画质 | 保留当前完整特效配置，是 PR A 后的对比基线 |
| 均衡 | 保留所有背景类型，适度减少粒子；四种 WebGL 背景降低渲染像素和绘制频率 |
| 轻量 | 保留既有低性能模式行为 |

设备识别包含 iPhone、Android、iPad 桌面 UA（MacIntel + 多点触控），并补充主指针为触控且不支持悬停的设备。不是仅按窗口宽度判断；用户始终可以手动覆盖。既有 `low_perf_manual` 手动选择继续优先，新增本地设置键 `device_graphics_quality_v1`；它不参与家庭同步。

## 均衡档具体变化

| 背景 | 原画质 → 均衡 |
| --- | --- |
| 极光、棱镜、时空网格、极速跃迁 | DPR 上限 2 → 1；绘制频率随屏幕刷新 → 约 30fps；动画时间继续按经过时间计算 |
| 银河 | 面积粒子系数 1/1000 → 1/1500，仍保留至少 30 颗星 |
| 流星雨 | 星星 40 → 28，流星 6 → 4 |
| 孔明灯 | 35 → 24 |
| 萤火虫、银杏雨 | 50 → 34 |
| 万象字阵 | 网格间距 45 → 56，字形大小和原运动节奏不变 |
| 甲骨流沙 | 网格间距 40 → 50，保留点金交互 |
| 烟花 | 主要爆炸粒子约减少三分之一，保留发射节奏、造型与交互 |

Canvas 中依赖帧推进的动画此次只减密度，避免直接降帧导致慢动作。CSS 动画保持时长；不改全局 UI 动画、文字分辨率、打卡反馈、业务计时、扣款、同步频率。切换档位会重建背景粒子/画布，因此图案可能不同；这不是逐像素相同的截图对比。

在原先实际 DPR=2、60fps 的 WebGL 场景中，DPR=1 后每帧像素数约为 1/4，30fps 后每秒片元工作量理论约为原来的 1/8。**这不是整机省电 87.5%**：屏幕、CPU、系统与网络开销没有按比例消失；rAF 调度仍跟随屏幕刷新，只限制实际 WebGL 绘制。无动态背景时，本次优化收益可能很小。

## iPad 10 实机对比

- 保持相同亮度、网络、音量、背景和操作；不要充电、录屏或同时运行其他重任务。
- 先让机器恢复到接近同样的温度；每档运行约 15–20 分钟。两次之间冷却，不把上一轮余热当作下一档结果。
- 第一轮 A→B，第二轮 B→A，减少测试顺序的影响；页面打开后先等待约 30 秒再计时。
- 分别测“首页停留”和“正常滚动/打卡”两种使用方式；观察字阵、背景柔和度、点击延迟、滚动、发热和电量变化。
- 电池百分比粒度粗，单次变化不能当精确功耗；多轮结果一致后再决定是否合并或调整参数。
- 页面切到后台再回来，检查背景正常恢复；旋转屏幕，检查背景尺寸及顶部按钮安全区。

## 自动验证

新增测试覆盖手机/iPad 识别、旧设置兼容、设置不可读、自动/手动优先级、30fps 节奏、原/均衡/轻量切换、普通设置持久化、预览不持久化、背景装备隔离、CSS 粒子恢复、Canvas 绘制减少、四种 WebGL 的分辨率与实际绘制次数、隐藏暂停及取消背景后的清理。继续运行扣款/同步、PR A 能效和安全区全部回归测试。
