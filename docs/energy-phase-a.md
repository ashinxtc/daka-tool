# 能效优化 A：减少主程序无效工作

基线：`c9430b4`（已合并的 PR #2）。本批不调整画质、帧率、粒子数量、同步轮询间隔或账目协议；3D 展厅完全排除。

## 实施内容

- 禁言显示移到 `SilenceBanner`。原来的主 App 无条件 2 秒更新已移除。只有有效禁言时才启动局部计时，到期才更新共享禁言记录，恢复前台时重新核验。
- `useVisibleClock` 使用真实时间计算业务期限，页面隐藏时停止显示计时，前台恢复时立即刷新。探险悬浮入口保留已完成待领取 UI，但不再为这些记录运行秒级计时；到达结束时间后也停止计时。
- 动态背景的 RAF 统一接入仅用于装饰的可见时钟。隐藏、pagehide 时取消待执行回调；恢复时继续原画布和粒子，动画时间不包含隐藏时长。业务期限不使用该时钟。
- 背景 CSS 动画随页面可见性暂停，保留原样式与随机星点位置。
- 极光、时空背景缓存颜色转换结果，在颜色变化时重算，减少每帧创建数组。
- 现有组件卸载清理接入同一取消机制；开发热更新清理共享监听器。

## 验证

运行 `npm run test:all` 和 `git diff --check`。

- 领域/存储及调度器单元测试：25 项（原 21 项 + 新增 4 项）。新增覆盖隐藏取消、恢复时间步长、隐藏期间卸载、隐藏时初始化、pagehide/pageshow 与调度器释放。
- 浏览器回归：原账目 14 项；能效新增 9 项通过。禁言、探险、Canvas 和 CSS 在 Chromium 与 WebKit 各执行一次；四种 WebGL 背景在 Chromium 软件渲染中检查，WebKit 对应 WebGL 测试明确跳过。
- 能效浏览器测试挂载真实组件并用包装父组件计数：禁言更新不增加父组件渲染次数；完成/隐藏后没有 1 秒、2 秒 UI 计时器；背景隐藏后绘制计数不增加；恢复使用同一个 Canvas；切换/卸载后无继续绘制。
- 测试中可见性事件为模拟，WebKit 使用 iPad 视口，均不能替代实体 iPad 主屏幕应用测试。没有测量省电百分比或机身温度。
- 生产构建不包含测试页面。外部网络在原账目 E2E 中被阻止，节假日降级日志为预期。

## 本批边界

只处理明确的页面隐藏与组件卸载，没有根据弹窗外观推断背景是否被完全遮挡，避免半透明弹窗下突然冻结背景。前台静置降帧、移动端均衡画质、本机模式偏好留给下一批；不改变当前用户的手动画质选择。没有大范围重写整个应用的状态管理。

建议在预览版实际验证：正常打卡/转盘、禁言到期、探险完成及领奖、切换背景、锁屏/解锁、多次切出再返回。帧率、分辨率和粒子数量与正式版保持相同；收益先体现为减少无效执行，不承诺单独解决复杂背景持续绘制造成的全部发热。
